# 8. Requirement Gap Map

Known examples:

```text
Business intent
Actor
Trigger
```

Potential unknowns:

```text
Allowed fields
Lifecycle/state restrictions
Validation
Authorization
Audit
Performance
Availability
Concurrency
External system behavior
Event behavior
Acceptance criteria
```

Questions should be:

- Prioritized
- Assigned to the correct owner
- Marked blocking/non-blocking
- Linked to affected artifacts

Do not dump 30 questions at once.
