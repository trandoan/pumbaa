# 15. Implementation Context

Developers receive an **Implementation Context / Implementation Intent**.

Contains relevant:

- Business Outcome
- Requirement
- Acceptance Criteria
- HLD
- Architecture Decisions
- Component Design
- Affected Components
- Dependencies
- Constraints
- Business Rules
- NFRs
- Test Intent
- Open Questions
- Responsibilities
- Non-responsibilities
- Failure handling
- Operational expectations

Principle:

> **AI writes code; developer owns code.**

Developers must understand why code exists and validate it.

Cursor is the primary AI coding interface.

No MCP required.
