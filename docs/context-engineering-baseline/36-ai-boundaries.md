# 36. AI Boundaries

AI must **not**:

- Invent requirements
- Invent business decisions
- Invent architecture decisions
- Treat unknown as fact
- Convert inference into confirmed dependency
- Approve security
- Approve release
- Decide business policy
- Decide security exceptions
- Decide operational ownership
- Treat "tests passed" as sufficient evidence
- Invent authoritative thresholds
- Silently resolve conflicting sources
- Claim an impact is confirmed when it is only suspected

Principle:

> AI assists; humans decide.
