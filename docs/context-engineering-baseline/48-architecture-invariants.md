# 48. Architecture Invariants

The following invariants define the baseline architecture.

1. **Context Graph is central.**
2. **Evidence preserves provenance.**
3. **Unknown is not a fact.**
4. **Inference is not a decision.**
5. **Decision is not implementation evidence.**
6. **Git/current source is implementation authority.**
7. **Change is the central impact-analysis object.**
8. **Repository is not the impact boundary.**
9. **Testing is cross-cutting.**
10. **Production Readiness starts early.**
11. **Monitoring and alerting are designed early.**
12. **Operational ownership is explicit.**
13. **Rally is not engineering truth.**
14. **DONE Rally items are never reopened.**
15. **AI assists; humans decide.**
16. **Historical context is preserved.**
17. **Context Status and Delivery Status are separate.**
18. **RAG retrieves context; it does not establish truth.**
19. **Catalog is a map, not a cache.**
20. **MCP is not required.**
21. **CI is not required.**
