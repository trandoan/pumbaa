# 44. Impact Analysis

Impact Analysis is a central capability.

```text
Change
   │
   ▼
Impact Analysis
   │
   ├── Business Impact
   ├── Requirement Impact
   ├── UX Impact
   ├── Design Impact
   ├── Code Impact
   ├── API Impact
   ├── Event Impact
   ├── Data Impact
   ├── Test Impact
   ├── Security Impact
   ├── Operational Impact
   └── Release Impact
```

The result should identify:

- Affected repositories
- Affected services
- Affected components
- Affected contracts
- Affected tests
- Affected operational artifacts
- Required actions

Potential impact should be clearly distinguished from confirmed impact.
