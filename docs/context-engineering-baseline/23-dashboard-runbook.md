# 23. Dashboard / Runbook

Dashboard is an artifact.

```text
Arrangement Service
   ├── Production Dashboard
   ├── Alerts
   └── Runbooks
```

Runbook should cover:

- What happened?
- What to check first?
- Likely causes
- Diagnostic steps
- Mitigation
- Rollback/recovery
- Escalation
- Owner

AI can draft from existing context.

Human/Ops review remains authoritative.
