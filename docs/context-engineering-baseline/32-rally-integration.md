# 32. Rally Integration

Rally is the work tracking and presentation layer.

It is **not engineering truth**.

```text
Context Graph
      │
      ▼
Required Work
      │
      ▼
Rally Work Item
      │
      ▼
Rally Execution
      │
      ▼
Evidence
      │
      ▼
Context Graph
```

The engineering context remains outside Rally.
