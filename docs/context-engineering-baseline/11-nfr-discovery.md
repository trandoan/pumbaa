# 11. NFR Discovery

Use dimensions:

- Performance
- Availability
- Resilience
- Consistency
- Security
- Scalability
- Observability
- Data retention/recovery/migration

Classification:

```text
RELEVANT
NOT_RELEVANT
UNKNOWN
INHERITED
```

Enterprise standards should be inherited.

If a specific requirement conflicts with an enterprise standard:

```text
Conflict
 ↓
Decision Required
```

AI does not decide the conflict.

Similar outcomes may provide candidate NFRs:

```text
Candidate
 ↓
Validate
 ↓
Inherit
```

No blind copying.
