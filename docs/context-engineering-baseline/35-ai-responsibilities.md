# 35. AI Responsibilities

AI is responsible for helping maintain and navigate context.

AI may:

- Extract knowledge from source artifacts
- Identify ambiguity
- Identify missing requirements
- Generate questions
- Prioritize unanswered questions
- Detect conflicts
- Map dependencies
- Perform impact analysis
- Generate context views
- Generate implementation context
- Generate test intent
- Identify missing evidence
- Prepare release paperwork
- Identify stale evidence
- Identify missing monitoring/alerting
- Generate candidate runbooks
- Summarize production feedback
- Connect code to design
- Detect design/code divergence
- Identify cross-repo impact
- Identify affected artifacts
- Prepare developer/reviewer/release/operations views

AI should be treated as a context-processing and reasoning layer.
