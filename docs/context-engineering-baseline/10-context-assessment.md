# 10. Context Assessment

Before detailed design, determine whether enough context exists to proceed.

Check:

- Business intent
- Business rules
- Relevant NFRs
- Dependencies
- Existing reusable capabilities
- APIs/events/data
- UX context
- Assumptions
- Pending decisions
- Source conflicts

Context Assessment is **not approval**.

It answers:

> **Do we know enough to move forward responsibly?**
